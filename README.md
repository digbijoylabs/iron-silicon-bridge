## Repository Layout
- `examples/ch01_*` .. `examples/ch18_*` — **139 chapter-indexed reference blueprints** (`COBOL`, `Python`, `JCL`, `RACF`, `REXX`, `Java`, `YAML`, `SQL`, `JSON`) mapped directly from each chapter's Field Deliverable summary.
- `code_catalog.json` — Machine-readable catalog mapping every `ch01`..`ch18` blueprint path to its source chapter and architectural pattern.
- `index.html` — Zero-dependency interactive browser workbench for modeling 4HRA MSU-to-Cloud TCO step-downs and inspecting raw `COMP-3` / EBCDIC byte representations.
- `llms.txt` & `CITATION.cff` — Structured discovery and scholarly citation metadata.
